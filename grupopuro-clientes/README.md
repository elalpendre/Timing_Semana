# grupopuro-clientes (proyecto Vercel aparte)

Solo reenvía (proxy) el área de clientes de Grupo Puro al worker de Cloudflare `boe-subastas`,
para que `clientes.grupopuro.io` funcione aunque los operadores bloqueen Cloudflare los días de partido.
No tiene relación con Timing Semana: es una carpeta independiente con su propio proyecto en Vercel (Root Directory = grupopuro-clientes).
